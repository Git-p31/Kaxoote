# Kaxoote — своя викторина в стиле Kahoot

Все типы вопросов бесплатно, без подписки и без ограничения на число игроков.

## Запуск
1. Один раз установи Node.js (версия LTS): https://nodejs.org
2. Дважды кликни **START.bat** (или в PowerShell: `npm install`, потом `npm start`).
3. В браузере откроется http://localhost:3000. Это экран ведущего: покажи его на проекторе или ТВ.
4. Игроки подключаются к **той же Wi-Fi**, сканируют QR-код или открывают адрес с экрана и вводят PIN.

Если телефоны не подключаются: при первом запуске Windows спросит про брандмауэр — нажми «Разрешить» для частных сетей.

## Типы вопросов
- Викторина — от 2 до 6 ответов, можно несколько правильных
- Правда или миф — подписи кнопок можно менять
- Введи ответ — игрок пишет сам, можно указать несколько вариантов написания
- Угадай число — шкала с допуском, чем ближе ответ, тем больше очков
- Расставь по порядку
- Опрос — без очков
- Слайд — информация без ответа

К каждому вопросу: картинка, время (5–240 сек), обычные, двойные или нулевые очки, пояснение после ответа.

## Управление ведущего
- Пробел, Enter или → — дальше
- Клик по имени в лобби — убрать игрока
- Кнопки внизу справа: звук, музыка, полный экран

## Где что лежит
- `quizzes/` — викторины (.json); их можно копировать и пересылать
- `public/uploads/` — загруженные картинки
